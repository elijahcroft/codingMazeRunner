Sensors and Python examples
RETURN ONE OF THESE FROM steer()
"left" "right" "straight" Left and right are from your cycle's point of view.
YES / NO SENSORS · True or False
wall_ahead() wall_left() wall_right() Is the very next square that way solid? Trails count as walls.
NUMBER SENSORS · how far until something solid
space_ahead() space_left() space_right() Free squares in a straight line that way: 0, 1, 2…
ALSO WORKS
if/elif/else, and or not, variables, your own def helpers, max(a, b) min(a, b) abs(n), and print("note").
EXAMPLE · compare numbers 
def steer():
    if space_left() > space_right():
        return "left"
    return "right"
EXAMPLE · remember things between turns 
turns = 0

def steer():
    global turns
    turns += 1
    print("turn", turns, "room ahead", space_ahead())
    return "straight"
