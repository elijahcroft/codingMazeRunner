          Sensors and Python examples
          

            

            RETURN ONE OF THESE FROM steer()
            
"left" "right" "straight" Left and right are from your cycle's point of view.

            YES / NO SENSORS · True or False
            
wall_ahead() wall_left() wall_right() Is the very next square that way solid? Trails count as walls.

            NUMBER SENSORS · how far until something solid
            
space_ahead() space_left() space_right() Free squares in a straight line that way: 0, 1, 2…

            ALSO WORKS
            
if/elif/else, and or not, variables, your own def helpers, max(a, b) min(a, b) abs(n), and print("note").

            EXAMPLE · compare numbers
            
def steer():
    if space_left() > space_right():
        return "left"
    return "right"

            EXAMPLE · remember things between turns
            
turns = 0

def steer():
    global turns
    turns += 1
    print("turn", turns, "room ahead", space_ahead())
    return "straight"

Light Cycles · cheat sheet

  
    
    
  • Your cycle never stops. Every turn it moves one square and leaves a wall of light behind it.
    • 
    
  • Walls and every trail are solid, even your own. Two cycles meeting head-on are both out.
    • 
    
  • Last cycle riding wins. In a class battle you get 1 point for every rider you outlast.
    • 
  

  
How your code runs

  
Every turn the game calls your steer() and asks "Which way?" Your function answers with return. You never call steer() yourself. print() only talks to you: the game never hears it.

  
"left""straight""right"

  
Always in quotes, always lowercase.

  
Left and right turn with your cycle

  

    
straightleft▲right
facing up the screen

    
left▶straightright
facing right: left is UP the screen!

    
Pretend you are riding the cycle. Look at the arrow on its head: "left" means its left, not yours and not the screen's.

  

  
The 6 sensors

  

    
wall_ahead()True if the very next square ahead is solid (a wall or a trail).

    
wall_left()True if the next square to your cycle's left is solid.

    
wall_right()True if the next square to your cycle's right is solid.

    
space_ahead()How many free squares in a straight line ahead: 0, 1, 2…

    
space_left()How many free squares in a straight line to the left.

    
space_right()How many free squares in a straight line to the right.

  

  
Two tiny examples

  

    
Turn before the wall
def steer():
    if wall_ahead():
        return "left"
    return "straight"

    
Use a number sensor, and print to see it
def steer():
    print("room ahead:", space_ahead())
    if space_ahead() < 3:
        return "right"
    return "straight"

How Light Cycles works

      
    
        
  1. Your cycle never stops.It moves one square every turn and leaves a wall of light behind it. Walls and every trail, even your own, are solid. Hit one and you're out. Last cycle riding wins.
    2. 
        
  2. Every turn, the game calls your steer().The game is like a driving instructor: every turn it asks your steer() "Which way?" You never call steer() yourself. The game does.
    3. 
        
  3. You answer with return.Your function says its answer out loud with one of these:
          
    return "left"     return "straight"     return "right"
    
          Left and right are your cycle's left and right, not yours. Watch the arrow on its head. print() is talking to yourself: the game never hears it.
